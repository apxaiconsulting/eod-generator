# EOD Generator

Instructions that turn raw daily work notes into a polished End-of-Day report for the AI Systems & Research Operations Specialist role at GFP.

## Use

- **Claude Code:** open this folder. `CLAUDE.md` loads automatically, so just paste the day's notes.
- **Claude Projects (claude.ai):** connect this repo, or paste the contents of `CLAUDE.md` into the project instructions.
- **Any other assistant:** paste `CLAUDE.md` as the system prompt or first message, then paste the notes.

## Follow-up outputs

After a report, ask for any of: AI / System Work Shipped Today, Research Output, Win for the Day, Performance Self-Assessment, Role Reconstruction Assessment, Pending Tasks.
